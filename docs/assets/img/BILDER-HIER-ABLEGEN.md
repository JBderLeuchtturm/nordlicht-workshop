# Bilder für das Workshop-Portal

Die Seite funktioniert **auch ohne Fotos** — überall, wo ein Bild fehlt, wird automatisch
eine gezeichnete Grafik (SVG) im NordLicht-Design angezeigt. Ihr müsst also nichts tun.

Wollt ihr echte Fotos einsetzen: einfach die Datei mit **genau diesem Namen** in diesen Ordner
legen (`docs/assets/img/`), committen, pushen — fertig. Kein Code muss angefasst werden.

## Woher die beiden Logistik-Fotos nehmen?

Kostenlos und ohne Namensnennung nutzbar (auch kommerziell):

- **unsplash.com** — Suchbegriffe: `container terminal hamburg`, `cargo port dusk`, `warehouse shelves`
- **pexels.com** — Suchbegriffe: `logistics warehouse`, `shipping containers`
- **pixabay.com** — Suchbegriffe: `hafen hamburg`, `logistik lager`

Achtet darauf, dass das Motiv **dunkel bzw. ruhig** ist — die Bildunterschrift liegt unten
auf einem weichen Verlauf, sehr helle oder unruhige Bilder schlucken den Text.

## Porträts

Kein Foto zur Hand? Dann lasst die Dateien einfach weg: Die Seite zeigt stattdessen die
Initialen (JB / TH / DH) auf dunklem Grund — sieht bewusst gestaltet aus und passt zum Design.

## Tipp zur Dateigröße

Fotos vor dem Hochladen auf **unter 400 KB** verkleinern (z. B. mit squoosh.app),
sonst lädt die Seite unnötig langsam.
